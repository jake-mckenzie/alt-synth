# Playing classic game melodies in alt-synth

Start with these short NES/SNES motifs, then use the note-to-key reference to
work through music you already have. These are melody exercises, with simplified
timing, rather than full soundtrack arrangements.

## Set up

1. Start alt-synth. It opens in QWERTY view.
2. Use the default octave: **A plays C4**, and **K plays C5**. If you changed
   octaves, use the arrow keys until those labels return.
3. Start with **Chiptune**. Use the Filter button to select **Bell** or **Piano**
   for a softer sound.
4. Leave Space released while learning. Release each note before the next,
   including repeated presses of the same key.

Capital letters below are key labels: **do not hold Shift**. Shift itself plays
a bass note in QWERTY mode. Semicolon and apostrophe are literal playing keys.
Caps Lock is unused.

## Reading the examples

- A key by itself means press and release it.
- `·` means silence for one timing slot; do not press the period key.
- `~` means keep holding the previous key for another slot.
- `|` separates groups; it is not a key to press.
- `(Z+B)` means press both keys together.

For the snippets, start with one slot per slow spoken count. Use a recording to
learn the phrasing once the finger movements feel comfortable. There is no
automatic sequencer or tempo control: you supply the timing.

## Super Mario Bros. — opening motif (NES)

Choose **Chiptune** and keep the notes short and springy. The semicolon key is
the repeated opening note; `R` is the higher peak and `G` the lower response.

```text
; ; · ; | · K ; · | R ~ · · | G ~ · ·
```

Practice the repeated key first, lifting fully between taps. Then add the jumps.
This is a brief opening excerpt. [Hoffman Academy's tutorial](https://app.hoffmanacademy.com/lessons/piano/super-mario-overworld-theme-song/video/)
explains the opening's notes and rests.

## Zelda's theme / lullaby — opening motif (SNES)

This theme appears in *A Link to the Past*, before its later use as an ocarina
song. [Theme background](https://www.zeldadungeon.net/storytelling-through-sound-the-beauty-of-returning-themes/).

Try **Bell** or **Piano**. This short practice excerpt uses a convenient register;
let the last note in each group linger.

```text
J L H ~ ~ ~ | J L H ~ ~ ~
```

Play without sustain first. Once comfortable, hold Space during one group and
release it between groups so the notes do not accumulate.

## Bonus: Korobeiniki — a Tetris-associated folk melody

The familiar arrangement is especially associated with **Game Boy Tetris**,
rather than the NES soundtrack. Its basis is the older Russian folk melody
“Korobeiniki.” [Soundtrack background](https://en.wikipedia.org/wiki/Tetris_(Game_Boy_video_game)).

Here is a simplified four-bar folk-melody exercise, rather than a transcription
of the game's arrangement. Choose **Chiptune** and count eight equal slots per
line: `1 & 2 & 3 & 4 &`. A held slot lasts as long as a played slot.

```text
; ~ J K L ~ K J
H ~ H K ; ~ L K
J ~ ~ K L ~ ; ~
K ~ H ~ H ~ ~ ~
```

Learn one line at a time. Join the lines slowly before increasing speed. Keep
Space released for a clear, detached melody.

## Add a simple accompaniment

These are original practice patterns, not the games' bass parts. Keep each
press short and use one key or chord per beat.

| Harmony | Bass and chord keys | Notes |
| --- | --- | --- |
| C major | `Z (B+G) Z (B+G)` | C3, then E3+G4 |
| C major triad | `(Z+D+G)` | C3+E4+G4 |
| A minor triad | `(/+A+D)` | A3+C4+E4 |
| F major triad | `(N+H+K)` | F3+A4+C5 |
| G major triad | `(,+J+L)` | G3+B4+D5 |

Start with a single bass note under the melody. Add a chord only when you can
keep both parts steady. Some keyboards cannot register certain combinations;
try fewer notes if one does not sound. Backspace silences everything.

## Note-to-key reference

All pitches below use the default octave. The rows follow musical pitch order,
not physical keyboard order. A flat uses the same key as the equivalent sharp:
for example, B-flat is A-sharp (`U` for A#4).

| Register | Notes, from low to high | Keys in matching order |
| --- | --- | --- |
| Bass | C3 C#3 D3 D#3 E3 F3 F#3 G3 G#3 A3 | `Z X C V B N M , . /` |
| Main | C4 C#4 D4 D#4 E4 F4 F#4 G4 G#4 A4 A#4 B4 | `A W S E D F T G Y H U J` |
| Upper | C5 C#5 D5 D#5 E5 F5 F#5 G5 G#5 A5 A#5 B5 | `K O L P ; ' Q R I [ ] \` |
| High | C6 C#6 D6 D#6 E6 F6 F#6 G6 G#6 A6 | `1 2 3 4 5 6 7 8 9 0` |

Lighter keys are natural notes; darker keys are sharps. This does not indicate
volume. The extra upper-row notes are interleaved around the original home-row
bindings, so use the displayed note labels rather than assuming left-to-right
pitch order.

For another tune, identify its note names and octave numbers, translate them
using this table, and practice two to four beats at a time. Use the arrows to
transpose the whole keyboard by octaves if needed; every table entry then moves
by the same amount. Chiptune is a useful starting sound for NES-style parts;
the other presets offer different colors for SNES melodies, without recreating
the original games' instruments exactly.
