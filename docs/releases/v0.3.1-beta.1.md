Linux x86-64 beta for testing the current alt-synth build and packaging.

- Linux builds now use the official prebuilt Raylib 5.5 library.
- Audio output and waveform buffering have a dedicated module.
- Piano and QWERTY layout, bindings, and rendering are grouped in one module.
- Core tests still run without Raylib or a display.

Extract `alt-synth_v0.3.1-beta.1_linux_x86_64.tar.gz` and run
`./alt-synth/alt-synth`. The Linux package targets glibc 2.35 or newer and
requires X11 or XWayland and system graphics and audio libraries.

Verify the archive with `sha256sum -c checksums.txt` before extracting it.
