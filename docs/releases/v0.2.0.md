The first C-based alt-synth release replaces the guitar chord browser with a
polyphonic desktop synthesizer.

- Play notes and chords from the home row or mouse, starting at middle C.
- Switch between piano and standard QWERTY keyboard displays with F2.
- Choose Chiptune (the default), Piano, Warm keys, Bell, or Soft synth.
- Hold Space for sustain; adjust octave, volume, and sound while playing.
- View the output waveform and active-note levels, with help available on F1.
- Build directly with `./build.sh`; no Go or Make toolchain is required.

### Linux download

Extract `alt-synth_v0.2.0_linux_x86_64.tar.gz`, then run `./alt-synth/alt-synth`.
The font and Raylib are embedded or statically linked; Linux graphics and audio
system libraries are still required. The package is built on Ubuntu 22.04 and
needs glibc 2.35 or later and an X11 display (or XWayland). Verify the download
against `checksums.txt` with `sha256sum -c checksums.txt`.

External MIDI input and macOS/Windows release packages are not included.
