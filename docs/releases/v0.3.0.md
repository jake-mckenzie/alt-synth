alt-synth now opens in QWERTY view, with 55 playable keys. Piano view spans two
octaves (C4–C6 at the starting octave) and retains the original key bindings.

- Use the top-row controls for help (F1), keyboard view (F2), and tone (F3 or Tab).
- Both keyboard views occupy half the window height. Text and controls scale as
  the window grows, and the graphs stay in place when switching views.
- Rapid tone changes preserve the current blend. Opposing octave and volume
  shortcuts cancel when pressed together, including at the limits.

### Linux x86-64

Extract `alt-synth_v0.3.0_linux_x86_64.tar.gz` and run `./alt-synth/alt-synth`.
The package requires glibc 2.35+, X11 or XWayland, and system graphics and audio
libraries. Use `sha256sum -c checksums.txt` to verify the archive.
